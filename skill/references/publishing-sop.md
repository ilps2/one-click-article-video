# 微信「公众号 ↔ 视频号」互链投放 SOP

> 适用:one-click-article-video 产出的视频 + 封面 + 文案的微信侧投放
> 目标:视频号吃官方流量倾斜 + 公众号粉丝冷启动 + 双向导流闭环
> 操作均在微信手机版(App)内,个别步骤需电脑

---

## 第 1 步:视频号绑定公众号(必做,一次性)

**为什么**:不绑定就无法在视频里挂公众号文章链接,视频号主页也不会显示公众号入口。

**操作**(微信手机版):
1. 打开微信 → 底部「发现」→「视频号」
2. 点右上角**人像图标**进入个人主页
3. 点右上角「**···**」→「**设置**」
4. 点「**账号管理**」→「**绑定公众号**」
5. 输入你的公众号名称 → 搜索 → 选中
6. 页面提示「**请公众号管理员确认**」→ 用公众号管理员的微信扫描/确认

**验证(必须看到)**:
- 回到视频号个人主页 → 头像下方出现**公众号名称**链接
- 打开公众号 → 公众号主页「视频」标签下出现视频号入口

---

## 第 2 步:发布视频时挂公众号文章链接(每期必做)

**操作**(手机版,发布已渲染好的 9:16 mp4):
1. 视频号主页 → 点右上角「**发表视频**」(或相机图标)
2. 从相册选择 `douyin-wechat-916.mp4`(9:16 视频)
3. 填写:
   - **描述**:用发布文案里的「微信(公众号)」段,或单独写钩子句(建议 ≤100 字)
   - **封面**:选 `cover-wechat-square.png`(1:1 封面,视频号默认展示方形封面)
4. 点「**添加**」(或「扩展链接」)→ 选「**公众号文章**」→ 搜索/选择对应文章
5. 点右上角「**发表**」

**电脑版备选**(定时发布/批量):浏览器打开 `channels.weixin.qq.com` → 微信扫码登录 → 「发表视频」→ 同样流程添加文章链接

**验证(必须看到)**:
- 视频发布后,视频下方出现**蓝色文章链接卡片**
- 点开视频 → 链接可点击跳转公众号文章

---

## 第 3 步:公众号文章里插入视频号视频(反向导流)

**操作**(公众号后台,电脑):
1. 打开公众号后台 `mp.weixin.qq.com` → 新建图文
2. 光标放到要插视频的位置 → 顶部工具栏点「**视频**」→ 选「**视频号**」
3. 搜索你的视频号名字 → 选中刚发布的视频 →「**插入**」
4. 正文里出现视频卡片(读者可直接在文章里播放)

**验证(必须看到)**:
- 预览文章 → 视频卡片可播放
- 视频卡片下方有「**视频号**」入口,点进去到你的主页

---

## 第 4 步:冷启动组合拳(发布节奏)

**发布当天**(黄金 3 小时):
1. **公众号推文**(含视频号视频卡片)→ 文末加一句:「想看动态版,视频号搜 XXX」
2. **视频号同步发** 9:16 视频(带文章链接)
3. **朋友圈转发**公众号推文(视频号社交推荐的第一跳板)
4. 把视频转发到 2-3 个相关微信群(不刷屏,选精准群)

**节奏建议**:每周 2-3 期,固定时间(如周二/周五晚 8 点);视频号算法吃"稳定更新"信号

## 第 5 步:数据验证(看什么)

| 指标 | 在哪看 | 健康值 |
|---|---|---|
| 视频完播率 | 视频号「···」→ 创作者中心 → 数据中心 | ≥30% |
| 链接点击率 | 创作者中心 → 单条视频数据 | 有正向即可 |
| 公众号涨粉 | 公众号后台 → 用户分析 | 视频发布后 24h 有增量 |
| 文章阅读来源 | 公众号后台 → 内容分析 → 来源构成 | 出现「视频号」来源 |

**验证周期**:每期发布 3 天后看一次数据,连续 4 期对比,完播率稳定 30%+ 就保持节奏。

## 常见问题

**Q: 绑定公众号提示"主体不一致"?**
A: 个人视频号只能绑本人运营的公众号;若视频号用企业主体,公众号也必须是同主体。

**Q: 发布时找不到"添加链接"?**
A: 确认已绑定公众号(第 1 步);链接功能只在绑定的公众号**已发布过文章**后可选。

**Q: 视频号封面上传什么规格?**
A: 视频号封面方形(1:1)优先,用 `cover-wechat-square.png`;横条 `cover-gzh-horizontal.png` 用作公众号推文头图。

**Q: 能直接发小红书/抖音的版本吗?**
A: 各平台用对应规格:抖音发 9:16 + 抖音封面;小红书发 3:4 + 小红书封面,文案见 `发布文案.md`(已过平台审核适配)。
