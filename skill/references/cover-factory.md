# 封面工厂:钩子文字 × 意象化模板

公众号封面 = 钩子文字 + 意象化配图。这是结构性优势,不是潜力判断。

## 为什么这个组合是主战场

**钩子文字是 diffusion 的致命伤,是 SVG 的绝对主场**
- 公众号封面点击率变量 = 标题/钩子文字。扩散模型生成汉字全是乱码,这个市场它根本进不来
- SVG/HTML 文字:精确、任意字号、可编辑、可复用

**简单配图不触发精度比较**
- 意象化色块/器物/圆点阵,观众不会拿去和照片比(不像人物、产品)
- 踩过的坑都是「画了精度敏感对象」,纯氛围图没有这个坑

**成本结构匹配公众号产能**
- 一篇文章 2~3 张图(头图 + 文末卡 + 分享图),批量无压力
- 模板化:钩子文案 × 意象化模板 = 组合产出

## 实战公式(钩子类型 × 模板)

| 钩子文字类型 | 模板 | 例子 |
|---|---|---|
| 数字冲击 | 大数字排版 | 「月薪 3000 到 3 万,我做对了这 3 件事」 |
| 情绪共鸣 | 留白+大字 | 「你那么懂事,一定很累吧」 |
| 悬念缺口 | 半句遮字 | 「其实大多数人的努力,都是在____」 |
| 身份代入 | 器物意象 | 「懂宋瓷的人,从不着急」 |
| 反常识 | 对比色块 | 「越克制的人,越强大」 |

## 意象化素材库(纯 CSS/SVG 可画)

- **色带**:渐变横条/竖条,主色+点缀色对比
- **开片纹理**:细线裂纹(宋瓷风格,`stroke` 细线 + 低透明度)
- **圆点阵**:网格排列的圆点,大小/颜色渐变
- **网格**:细线网格背景,配大字
- **器物剪影**:花瓶/碗/杯的 SVG path 剪影 + 渐变填充

## 设计规则

1. **钩子文字最大**:标题占版面 40-60%,字重 700-800,一眼读完
2. **留白**:大留白 = 高级感(计白当黑),别把版面填满
3. **配色**:主色 ≤ 15% 版面(点缀),底色 60%+,文字色 25%;低饱和
4. **单文件自包含**:html2canvas 内联进 HTML,双击即用,离线可导出
5. **双规格**:横版 900×383(2.35:1)+ 方版 1080×1080,同一套元素两种排版
6. **导出干净**:编辑框/虚线框/悬停效果导出时隐藏,成品无编辑痕迹

## 模板文件

`references/cover-template.html` — 单文件模板(钩子文字 + 器物意象 + html2canvas 导出按钮)。用法:复制 → 改文字/配色/意象 → 浏览器打开 → 点「导出 PNG」→ 2x 输出。
