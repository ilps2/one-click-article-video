# 已验证设计系统

两套经实战验证的设计系统,同类文章直接套用配色/字体/意象。视频与封面共用同一设计系统(封面直接取配色/意象/字体);意象元素全部纯 SVG/CSS,无外部图片——确定性渲染 + 零资源依赖。

## 1. 宋瓷天青风(器物 / 审美 / 极简 / 设计语言类)

- **适用**:宋瓷美学、器物、东方极简、设计语言、模板/技能类文章
- **配色**:月白底 `#F6F4EF` / 天青主色 `#7FA8B5`(点缀,<15% 版面)/ 黑釉文字 `#33302B` / 茶褐点睛 `#9C6B4E` / 象牙白卡底 `#FAF9F5`
- **字体**:标题 Songti SC(宋体,衬线高级感),正文 PingFang SC,代码/提示词 Menlo
- **意象**:器物剪影(花瓶 SVG path + 天青渐变)、开片细线、圆点阵、色带
- **原则**:大留白(计白当黑)、大圆角 36-44px(温润如玉)、漫反射阴影、动效克制
- **换肤轮播**(展示多色模板的核心手法):6 釉色主题用 fromTo 链式切换(天青→粉青→月白→黑釉→窑变→象牙白),每主题文字随底深/浅自动变色(浅底深字/深底浅字),**初始主题也要单独演示一次**,别跳过

## 2. 深夜烟火风(情感叙事 / 人物故事 / 市井烟火类)

- **适用**:人物故事、情感共鸣、怀旧悼念、市井烟火、励志叙事
- **配色**:深蓝夜底 `#12141A`(顶部 radial-gradient `#1D212B`)/ 炭火橙 `#E8843C`(强调色 + CTA)/ 暖白文字 `#F5F1EA` / 灰蓝次要文字 `#7A8CA0`
- **字体**:标题宋体或粗黑体(700-800 字重),正文 PingFang SC
- **意象**:月亮(SVG 圆 + 光晕 + 环形描边)、烟雾曲线(半透明 stroke path,`rgba(245,241,234,.1)`)、炭火圆点(径向渐变 + box-shadow 光晕,有限 repeat + yoyo 闪烁)、烤串剪影
- **节奏**:大字金句居中停留(如「雪化成水,峰留人间」);对照结构(如「考 vs 烤」「送人上岸 vs 等人上桌」)用 `VS` 大字分隔,两行对称排版
- **CTA**:橙色胶囊按钮 + 账号名引导关注

## 3. 财富琥珀金风(观点 / 财富 / 认知类)

- **适用**:财富思维、认知观点、职场成长、名人金句类(如「马斯克现金流」)
- **配色**:月牙白底 `#F6F4EF` / 琥珀金文字 `#B3862F`(浅底上对比度 3:1 达标)/ 亮金 `#D9A441`(卡片徽章、步骤圆、CTA 底,配 `#FAF9F5` 字)/ 黑釉主文字 `#33302B` / 次文字 `#8A867D` / 金卡 `#FDF8EC` + 金边框
- **字体**:标题宋体(serif 700)或粗黑体,正文 PingFang SC
- **意象**:增长曲线(SVG path,`stroke-dashoffset` 描边动画从起点画到终点,配虚线对比线 = 线性 vs 复利)、金币圆点(radial-gradient `#E8C96A→#D9A441→#A87A24` + 光晕)、`path-card.gold` 高亮卡片
- **结构**:两条路对比(卖时间 vs 建资产,灰色卡 vs 金色高亮卡 + 徽章「上班/现金流」)、三步走(编号圆 1-2-3 上下堆叠)、金句双行(第二行琥珀金高亮)
- **CTA**:金色胶囊按钮 + 账号名

## 6 幕叙事模板(按文章类型选)

| 类型 | 幕结构 | 实例 |
|---|---|---|
| A. 产品/方法型 | 引子(意象+标题)→ 念头/问题 → 能力/方法 → 演变/步骤 → 主角展示(可做交互演示如换肤)→ 金句+CTA | 宋瓷 Skill |
| B. 情感叙事型 | 引子(氛围意象+标题)→ 现象 → 巧合/缘分 → 对照(双关如「考vs烤」)→ 金句升华 → 致敬+CTA | 张雪峰替身 |
| C. 观点/财富型 | 引子(核心观点标题+隐喻图)→ 为什么 → 两条路对比 → 三步走(上下堆叠)→ 金句 → 行动号召+CTA | 马斯克现金流 |

## 封面钩子案例(类型 × 意象 × 验证)

| 文章 | 钩子 | 类型 | 意象 | 结果 |
|---|---|---|---|---|
| 宋瓷 | 「懂宋瓷的人,从不着急」 | 身份代入 | 花瓶+开片+圆点 | ✅ |
| 张雪峰替身 | 「雪化成水,峰留人间」 | 情绪/悬念 | 月亮+烟雾+炭火 | ✅ |
| 马斯克现金流 | 「现金流是生命线,复制是杠杆」 | 反常识金句 | 增长曲线+金币 | ✅ |

规律:钩子 ≤14 字、断两行、第二行或关键词用强调色(浅底必须用加深色保证对比度)。

## 用法

1. 判断文章类型 → 选设计系统 → 套配色/字体/意象
2. 意象元素全部内联 SVG/CSS,可微调(色值、尺寸、位置)
3. 新文章类型做出新设计系统后,回填本文件
