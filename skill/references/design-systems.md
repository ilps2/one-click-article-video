# 已验证设计系统

两套经实战验证的设计系统,同类文章直接套用配色/字体/意象。视频与封面共用同一设计系统(封面直接取配色/意象/字体);意象元素全部纯 SVG/CSS,无外部图片——确定性渲染 + 零资源依赖。

## 1. 宋瓷天青风(器物 / 审美 / 极简 / 设计语言类)

- **适用**:宋瓷美学、器物、东方极简、设计语言、模板/技能类文章
- **配色**:月白底 `#F6F4EF` / 天青主色 `#7FA8B5`(点缀,<15% 版面)/ 黑釉文字 `#33302B` / 茶褐点睛 `#9C6B4E` / 象牙白卡底 `#FAF9F5`
- **字体**:标题 Songti SC(宋体,衬线高级感),正文 PingFang SC,代码/提示词 Menlo
- **意象**:器物剪影(花瓶 SVG path + 天青渐变)、开片细线、圆点阵、色带
- **原则**:大留白(计白当黑)、大圆角 36-44px(温润如玉)、漫反射阴影、动效克制
- **换肤轮播**(展示多色模板的核心手法):6 釉色主题用 fromTo 链式切换(天青→粉青→月白→黑釉→窑变→象牙白),每主题文字随底深/浅自动变色(浅底深字/深底浅字),**初始主题也要单独演示一次**,别跳过

## 2. 深夜烟火风(情感叙事 / 人物故事 / 市井烟火类)

- **适用**:人物故事、情感共鸣、怀旧悼念、市井烟火、励志叙事
- **配色**:深蓝夜底 `#12141A`(顶部 radial-gradient `#1D212B`)/ 炭火橙 `#E8843C`(强调色 + CTA)/ 暖白文字 `#F5F1EA` / 灰蓝次要文字 `#7A8CA0`
- **字体**:标题宋体或粗黑体(700-800 字重),正文 PingFang SC
- **意象**:月亮(SVG 圆 + 光晕 + 环形描边)、烟雾曲线(半透明 stroke path,`rgba(245,241,234,.1)`)、炭火圆点(径向渐变 + box-shadow 光晕,有限 repeat + yoyo 闪烁)、烤串剪影
- **节奏**:大字金句居中停留(如「雪化成水,峰留人间」);对照结构(如「考 vs 烤」「送人上岸 vs 等人上桌」)用 `VS` 大字分隔,两行对称排版
- **CTA**:橙色胶囊按钮 + 账号名引导关注

## 3. 财富琥珀金风(观点 / 财富 / 认知类)

- **适用**:财富思维、认知观点、职场成长、名人金句类(如「马斯克现金流」)
- **配色**:月牙白底 `#F6F4EF` / 琥珀金文字 `#B3862F`(浅底上对比度 3:1 达标)/ 亮金 `#D9A441`(卡片徽章、步骤圆、CTA 底,配 `#FAF9F5` 字)/ 黑釉主文字 `#33302B` / 次文字 `#8A867D` / 金卡 `#FDF8EC` + 金边框
- **字体**:标题宋体(serif 700)或粗黑体,正文 PingFang SC
- **意象**:增长曲线(SVG path,`stroke-dashoffset` 描边动画从起点画到终点,配虚线对比线 = 线性 vs 复利)、金币圆点(radial-gradient `#E8C96A→#D9A441→#A87A24` + 光晕)、`path-card.gold` 高亮卡片
- **结构**:两条路对比(卖时间 vs 建资产,灰色卡 vs 金色高亮卡 + 徽章「上班/现金流」)、三步走(编号圆 1-2-3 上下堆叠)、金句双行(第二行琥珀金高亮)
- **CTA**:金色胶囊按钮 + 账号名

## 4. 职场冷调灰蓝风(职场 / 沟通 / 打工人共鸣类)

- **适用**:职场现象、沟通边界、打工人共鸣、职场热文(实例:「已读不回,正在成为职场炎症」)
- **配色**:月牙白底 `#F6F4EF` / 冷灰蓝主强调 `#5E6E82`(渐变 `#7E8FA3→#46536A`,白字对比度 4.5:1+ 达标)/ 黑釉文字 `#33302B` / 次文字 `#8A867D` / 浅边框 `#DDE3EA`
- **字体**:标题宋体或粗黑体,正文 PingFang SC

## 动效升级库(来自宋瓷短视频参考样例,图形当主角)

纯文字视频容易显得"PPT",参考样例(6s 竖版)的核心手法:

1. **大图形主体**:器物/圆盘/徽章占画面 **1/3 以上**(直径 ≈ 600px),视觉主体是图形不是文字——不要只放小图标
2. **印章式内嵌文字**:标题/关键词嵌进大图形内部(圆盘内 2-3 行字,像盖章),文字成为图形的一部分,天然"有设计感"
3. **标签胶囊点缀**:主视觉外配 1 个小圆角胶囊(如「宋瓷 · SKILL」),信息层次:大图形 > 标题 > 胶囊
4. **开场集中入场(0-1s)**:主视觉一次到位——大图形 scale 0.6→1 + 淡入(back.out),标题随之浮现;之后静止展示(短视频 6s 级节奏,信息密度优先)
5. **文字密度**:信息型排版可加大文字密度(深色像素占比 1.5%+,对照:纯标题视频仅 0.4-0.6%)
6. 静止 ≠ 无动效:入场后的画面可以完全静止(短视频场景),把动效预算集中在开场 1 秒

适用:短视频(6-15s)标题卡/封面动效;长视频(30s+)作为**引子幕**开场,后续幕仍按 6 幕模板走。

## 动效逆向分析(拿到参考视频怎么学)

用户丢来一个 mp4 参考样例时,不靠肉眼猜,用 ffmpeg 抽帧量化还原它的动效设计:

```bash
# 1. 基本信息 + 抽帧(短片 8fps,长片 2fps)
ffprobe -v error -show_entries format=duration -show_entries stream=width,height,r_frame_rate -of default=noprint_wrappers=1 demo.mp4
ffmpeg -v error -i demo.mp4 -vf "fps=8" /tmp/demo/f_%03d.png -y

# 2. 帧间差异定位运动区域(python):相邻帧按 4×3 区域分块统计差异像素占比,
#    差异>3-4% 的区块即运动区域,记录 (时间, 区域, 变化%) → 得到动效时间线
#    (关键:低阈值 8 再做一轮,确认入场后是否完全静止/有无呼吸动效)

# 3. ASCII 渲染看布局:scale=54:96 转灰度,映射到字符,直接"看"构图
#    (元素位置、大小占比、图层关系;浅色元素与背景同色时用边框差异/相邻帧对比补判)

# 4. 提炼要点 → 回填动效升级库(大图形/印章/胶囊/集中入场/文字密度)
```

判定经验:运动集中在开头 1s = 集中入场式;多处持续运动 = 多元素错峰;入场后 0 变化 = 静止展示型。实测样例(6s 宋瓷短视频)结论:开场 1s 中部集中入场(大圆盘+文字),之后 5s 完全静止,文字密度 1.7%。

## 信息流排版规范(抖音/小红书/微信热门视频字号与留白)

用户明确要求对齐主流信息流视频观感(3 秒定生死,标题必须一眼读完),**这是硬性标准不是审美建议**:

| 元素 | 1080×1920 规范字号 | 实测翻车案例 |
|---|---|---|
| 主标题/钩子 | **100-140px**(占屏宽 65-90%,单行 ≤10-12 字) | 76px 标题被用户点名"文字太小" |
| 正文行 | **56-72px**(700 字重) | 54px 不够 |
| 小字/标签/说明 | ≥40px | 28-38px 偏小 |
| 内容占比 | **75-85%**(留白仅 15-25%) | 大留白 50%+ = "内容挤在中间" |
| 顶部 padding | ~100px(别 150px) | 150px 导致内容偏下感 |

要点:
- 竖屏信息流是"大字信息密度"路线,与宋瓷风的"大留白"只用于引子幕(封面/第一幕),正文幕按本表
- 封面 hook 同规格(抖音 96px+、小红书 80px+、微信 64px+、横条 54px+)
- 字号放大后立即检查:行宽 = 字数×字号 > 容器宽 1 个字就会"一行多一个字"尴尬换行 → 用 SKILL.md 的 fitLines 自适应缩字
- 换肤/金句/数字类用特大字号(130-160px)做视觉锚点

## 用法

1. 判断文章类型 → 选设计系统 → 套配色/字体/意象
2. 意象元素全部内联 SVG/CSS,可微调(色值、尺寸、位置)
3. 新文章类型做出新设计系统后,回填本文件
